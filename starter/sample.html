Colour

Neutrals carry text and structure. Each other colour has one meaning, written beside it.

  • --bg
    Page
  • --ink
    Titles and body text
  • --ink-2
    Metadata, summaries, tabs
  • --ink-3
    Counts and labels
  • --interact
    You can press this
  • --highlight
    Look here
  • --cat-1..4
    Figure marks only
  • --seq-1..5
    Ordered values in figures

Prose

Long text is set in the serif at a comfortable measure. Links inside prose are in ink with a faint underline, never the browser's blue. When one phrase must stand out, it is marked with the look-here colour, and nothing else uses that colour.
